# Gapwise UTM — look-only review

## Objective
Do a no-code walkthrough of the current codebase and preview state, then report back on what looks solid and what might deserve attention next. No files will be edited.

## Scope
- Visual: landing hero, monument viewer, upload panel, timetable grid, gap plan, dark/light consistency, mobile responsiveness.
- Architecture: route structure in `src/routes/index.tsx`, state management for auth/restoration/sync, encrypted-only cloud mode.
- Code health: duplication, dead code, complexity hotspots, accessibility.
- Assets: model-viewer setup, GLB/poster state, font and design-token usage.

## Deliverable
A short, grounded summary of observations plus a ranked list of optional next steps. This plan does not include any implementation or file changes.
