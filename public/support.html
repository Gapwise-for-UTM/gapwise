Gapwise Support

Help for Gapwise for UTM and the optional Gapwise AI connector.

Independent student project. Gapwise is not affiliated with, endorsed by, or an official service of the University of Toronto.

Product help

For non-sensitive bugs, setup problems, timetable-import issues, routing/data corrections, or feature questions, open an issue in the public Gapwise GitHub repository. Include what you were trying to do, the affected feature, browser/device information when relevant, and clear reproduction steps using non-sensitive data.

Do not post ACORN .ics files, OAuth credentials, access/refresh tokens, private timetable contents, encryption keys, or another person's data in a public issue.

Gapwise AI / connector help

For connector issues, include the AI client, whether the issue affects public campus tools or explicitly delegated private timetable tools, and the error message with private content removed.

If private AI access behaves unexpectedly, revoke it from Gapwise Account → AI while investigating. If Claude shows an outdated tool list after a server release, disconnect and re-add the Gapwise connector, then re-authenticate.

Security reports

Do not disclose exploitable vulnerabilities publicly. Follow the Gapwise Security Policy and use GitHub private vulnerability reporting when available.

Official university matters

For academic records, registration, university policy, accessibility accommodations, emergencies, examinations, or other matters requiring an authoritative University of Toronto answer, use the appropriate official university service. Gapwise route and planning output is not an official U of T determination.
