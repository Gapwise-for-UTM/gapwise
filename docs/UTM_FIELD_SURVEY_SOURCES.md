# UTM field-survey evidence sources

The current survey campaign uses these source classes conservatively:

- **UTM Facilities snow/ice strategy:** official named barrier-free entrance identities, including MN Main / Field side / Lot #1, CCT Link, EH Main / Rear ×2, OPH Main / Rear, and RIH Main. It does not publish exact door coordinates.
- **U of T Robotics conference logistics:** verifies an MN North entrance with a second-floor level context. It does not equate that identity with any Facilities entrance name or publish exact geometry.
- **UTM Library Entrance Closure Advisory:** verifies a library entrance from CCT.
- **UTM main-news coverage of Blackwood Gallery:** independently describes a doorway joining CCT to HMALC and refers to the CCT Link.
- **Current OpenStreetMap:** supplies source-backed physical entrance geometry where present. OSM door geometry does not by itself establish official UTM identity, ordinary public access, or accessibility.
- **U of T interactive map:** visual QA/corroboration only under the present Gapwise policy. Screenshot pixels and proprietary map assets are not coordinate sources.

All source records and retrieval dates live in `src/data/utm/provenance.ts`.
