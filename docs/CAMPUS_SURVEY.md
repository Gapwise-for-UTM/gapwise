# UTM campus field-survey workflow

Canonical field-survey maintenance guidance lives in [`data/docs/maintenance/field-survey.md`](https://github.com/Gapwise-for-UTM/data/blob/main/docs/maintenance/field-survey.md). Public contribution guidance lives at https://docs.gapwise.ca/data/contributing/.

This compatibility stub intentionally remains so older repository links do not break.
