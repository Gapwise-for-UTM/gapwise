# Institutional contact and escalation matrix

> **INTERNAL ROLE TEMPLATE — NO PRIVATE CONTACT CHANNEL IS ASSERTED AS STAFFED OR TESTED**

Keep the repository copy role-based. Names, personal contacts, provider-account identifiers, bridge details, and after-hours instructions belong in an approved access-controlled system.

| Event/request                         | Accountable role                  | Initial handling                                                                                         | Escalate to                                                       | Channel status                                                                                                              |
| ------------------------------------- | --------------------------------- | -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Vulnerability report                  | Security owner                    | Preserve report, use the published disclosure policy/private advisory intake, assess safe triage         | Product owner; privacy/legal if data or notification may be involved | Public policy and private GitHub advisory intake are repository-defined; staffing/response coverage requires confirmation  |
| Suspected security incident           | Incident lead designated for event | Preserve evidence, limit access, classify and contain under `../INCIDENT_RESPONSE.md`                    | Security, operations, privacy, legal, affected provider           | Runbook exists; named roles/private coordination channels and exercise evidence are unverified                             |
| Privacy incident/complaint/request    | Privacy owner                     | Authenticate safely, minimize copied data, log decision/deadline                                         | Security, legal, product owner, provider as applicable            | Privacy-governance process exists; staffed private contact remains human-confirmed                                         |
| Service outage/recovery               | Operations owner                  | Validate impact, preserve minimal telemetry, use recovery decision points                                | Incident lead, provider support, communications owner             | No dedicated public status service or response SLA is repository-verified                                                   |
| Accessibility feedback                | Accessibility owner               | Record affected surface/assistive context without unnecessary personal data                              | Product owner; privacy if sensitive data is supplied              | Public non-sensitive GitHub issue path is documented; private accessibility-specific channel remains pending               |
| AI/MCP permission concern             | Security/product owner            | Revoke/constrain through verified controls; preserve minimal evidence                                    | Privacy owner and AI service owner                                | Exact deployed cross-repository contract should be reconciled for an incident                                               |
| Institutional questionnaire           | Package owner                     | Freeze scope/cutoff, assign evidence owners, qualify unsupported answers                                 | Security, privacy, legal, accessibility, operations               | Preparation package only; accountable approvers must be named for each handoff                                              |
| Legal, trademark, or affiliation request | Authorized owner                  | Make no commitment/endorsement claim; preserve request                                                    | Counsel and authorized university contact if one exists           | Counsel/university contacts are not established by repository evidence                                                      |
