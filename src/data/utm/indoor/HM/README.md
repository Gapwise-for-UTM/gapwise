# HMALC / Library indoor survey scope

This directory is reserved for field-verified local indoor geometry for the Hazel McCallion Academic Learning Centre / Library side of the CCT ↔ HMALC Link.

Do not publish corridor nodes or edges from building-shape inference, screenshot tracing, or indoor phone GPS. Use the `/survey?building=HM` walkthrough recorder, reconcile the physical route on site, then add `floors.json`, `nodes.json`, and `edges.json` only when the local geometry is defensible under `../README.md`.
