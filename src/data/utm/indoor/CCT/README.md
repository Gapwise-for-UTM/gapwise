# CCT indoor survey scope

This directory is reserved for field-verified local indoor geometry for the Communication, Culture and Technology Building side of the CCT ↔ HMALC / Library Link.

Do not publish corridor nodes or edges from building-shape inference, screenshot tracing, or indoor phone GPS. Use the `/survey?building=CCT` walkthrough recorder, reconcile the physical route on site, then add `floors.json`, `nodes.json`, and `edges.json` only when the local geometry is defensible under `../README.md`.
